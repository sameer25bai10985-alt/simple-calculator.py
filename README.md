# simple-calculator.py
Simple Calculator (Python)

A basic command-line calculator built in Python that performs simple
arithmetic operations such as addition, subtraction, multiplication, and
division.

Features

-   Addition
-   Subtraction
-   Multiplication
-   Division
-   Input validation (invalid input & zero-division handling)

How to Run

1.  Clone the repository: git clone
    https://github.com/sameer25bai10985-alt/simple-calculator.git

2.  Navigate to the project folder: cd simple-calculator

3.  Run the program: python calculator.py

Example

Simple Calculator Choose an operation: 1. Add 2. Subtract 3. Multiply 4.
Divide

Enter your choice: 1 Enter first number: 10 Enter second number: 20
Result: 30
